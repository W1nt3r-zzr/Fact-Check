# AI事实核查系统用户研究原型

## 项目简介

本项目是用于研究AI事实核查系统在不同场景下的用户体验和效果的交互原型。

## 技术栈

- **React 18** - 前端框架
- **Vite** - 构建工具和开发服务器
- **Tailwind CSS** - 样式框架
- **Lucide React** - 图标库

## 实验设计

### 研究目的

评估AI事实核查系统在不同场景下的用户体验和效果，测试不同介入方式对用户判断和行为的影响。

### 实验流程

### 正常模式

#### 1. 前测问卷
- **目的**：收集被试基本信息、信息接触行为、隐私关注度、技术熟练度
- **平台**：问卷星
- **问题数量**：21题（人口学3题 + 信息接触行为3题 + 隐私关注3题 + 技术熟练度12题）
- **文件**：[前测问卷.txt](./前测问卷.txt)

#### 2. 实验体验
- **风险类型选择**：3种类型（养生谣言、财产诈骗、社会新闻）
- **场景数量**：5个场景（家庭微信群、社交媒体、知乎、搜索引擎、AI助手）
- **介入模式**：3种模式
  - 强力弹窗阻断（modal）
  - 侧边悬浮提示（bubble）
  - 被动右键调用（menu）
- **体验次数**：每个场景体验3种介入模式，共 5×3=15 次体验
- **预计耗时**：15-20分钟

#### 3. 后测问卷
- **目的**：测量实验后的隐私担忧、介入方式评价、行为意向、开放反馈
- **平台**：问卷星
- **问题数量**：12题（隐私担忧4题 + 介入评价3题 + 行为意向2题 + 开放反馈3题）
- **文件**：[后测问卷.txt](./后测问卷.txt)

### 管理员预览模式 🆕

为研究者和演示需求设计的快速预览功能：

**功能特性**:
- 欢迎页面可一键开启/关闭预览模式
- 开启后页面顶部显示"管理员预览模式"黄色徽章
- 评分阶段提供"⚡ 预览模式：跳过评分，直接进入下一场景"按钮
- 无需完成全部3种介入模式即可进入下一场景
- 快速遍历所有5个场景

**使用场景**:
- 研究者预览实验流程
- 向导师/合作者演示原型
- 快速验证功能实现
- 测试不同风险类型的内容展示

**如何使用**:
1. 打开应用，在欢迎页找到"管理员预览模式"开关
2. 点击开关开启预览模式
3. 正常选择风险类型和场景
4. 体验任意介入方式后，点击灰色"跳过评分"按钮
5. 直接进入下一场景，无需完成全部评分

### 实验变量

#### 自变量
1. **场景类型**（within-subjects）
   - 家庭微信群（c1）
   - 社交媒体（c2）
   - 知识问答（c3）
   - 搜索资料（c4）
   - AI助手对话（c5）

2. **介入模式**（within-subjects）
   - 弹窗阻断（i1）
   - 悬浮气泡（i2）
   - 右键菜单（i3）

3. **风险类型**（between-subjects）
   - 养生谣言（r1）：热柠檬水杀癌细胞
   - 财产诈骗（r2）：乡村振兴专项基金
   - 社会新闻（r3）：重大爆炸事故

#### 因变量
1. **烦躁度**（1-7分李克特量表）
2. **有用度**（1-7分李克特量表）
3. **模式偏好**（每场景选择最喜欢的模式）
4. **行为选择**（每种场景下的行为反应）

### 控制变量
- 年龄、性别、学历
- 信息接触行为
- 隐私关注度
- 技术熟练度

## 实验流程状态机

```
welcome（欢迎页）
    ↓ 选择风险类型
selection（模式选择页）
    ↓ 选择介入模式并体验
rating（快速评分页）
    ↓ 完成当前模式评分
    ├─ 还有未体验模式 → selection（继续选择）
    └─ 所有模式体验完 → mode-selection
mode-selection（模式偏好选择）
    ↓ 选择最喜欢的模式
behavior（行为选择）
    ↓ 选择行为反应
    ├─ 还有未体验场景 → selection（下一场景）
    └─ 所有场景完成 → complete
complete（实验完成）
    → 跳转后测问卷
```

## 功能特性

### 动态内容系统

根据用户选择的风险类型，系统会自动展示相应的内容：

**风险类型**:
- **养生谣言 (r1)**: 健康相关的虚假信息（如：热柠檬水治疗癌症）
- **财产诈骗 (r2)**: 投资理财诈骗信息（如：乡村振兴认养返利）
- **社会新闻 (r3)**: 虚假社会新闻（如：某地重大爆炸事故）

**动态内容展示**:

1. **微信群场景**:
   - 文章内容根据风险类型变化
   - 精选评论自动匹配（如：养生谣言会显示"健康管理师"、"李医生"等评论者）
   - 评论内容与风险类型高度相关

2. **小红书场景**:
   - 文章标题和内容动态变化
   - 评论区显示与风险类型匹配的用户评论

3. **知乎场景**:
   - 问题标题根据风险类型生成
   - 高赞回答内容动态变化
   - 额外回答者身份和内容自动匹配（如：财产诈骗会显示"反诈专员"、"受害者"等）

### 高保真场景样式

**微信群场景**:
- 使用真实微信配色方案
- 左侧聊天列表 + 右侧文章详情页布局
- 精确还原微信文章详情页样式
- 作者信息、阅读量、评论等元素完整呈现

**配色方案**:
- 背景色: `#EDEDED`, `#F7F7F7`
- 边框色: `#D6D6D6`
- 强调色: `#07C160` (微信绿)

## 研究者说明

### 被试分配建议

建议招募30名被试，每组10人：
- 养生谣言组（10人）
- 财产诈骗组（10人）
- 社会新闻组（10人）

### 平衡分组

基于前测问卷结果进行平衡：
- 性别（男女比例）
- 年龄（18-24, 25-34, 35-44, 45-54, 55+）
- 学历（高中及以下、大专、本科、硕士及以上）
- 信息接触类型（养生、财经、新闻）

### 数据分析计划

1. **描述性统计**：各变量的均值、标准差
2. **重复测量ANOVA**：比较场景、介入模式的主效应和交互效应
3. **配对t检验**：比较三种介入模式的评分差异
4. **相关分析**：隐私担忧与行为意向的关系
5. **回归分析**：预测用户接受度的关键因素
