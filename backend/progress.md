### 5. 自适应搜索策略 (中优先级)
**想法来源**: 当面对"信息不足，无法判断"的情况，可以适当增加搜索结果量来补充信息

**实现方案**:
```python
def adaptive_search(claim: str) -> List[SearchResult]:
    # 第一轮：标准搜索（5-8个结果）
    search_results = await search_with_bocha(claim, count=8)

    # 判断是否需要更多搜索
    if not enough_evidence(search_results):
        # 第二轮：补充搜索（15-20个结果）
        additional_results = await search_with_bocha(claim, count=20)
        search_results.extend(additional_results)

    return search_results
```

**考虑因素**:
- [ ] 搜索结果数量上限建议：**20-25个**
- [ ] 成本控制：博查API调用次数
- [ ] 响应时间：避免用户等待过久
- [ ] 信息质量：避免引入噪音数据

**判断依据**:
- 第一轮搜索结果的相关性
- 证据的权威性和多样性
- 是否存在明显的信息缺口

### 自适应搜索策略
**问题**: 固定数量搜索结果可能不足以支撑复杂信息核查
**解决方案**: 动态调整搜索结果数量
**优势**: 提高核查准确性，减少信息不足的情况
**风险**: 增加API调用成本和响应时间

### 智能信息提取
**当前**: 基于正则表达式的结构化信息提取
**优化**: 使用NLP模型提高提取准确性
**考虑**: 成本与收益的平衡
