# AI信息核查助手 - 浏览器插件

基于GLM-5的智能信息核查Chrome浏览器插件，帮助你快速验证网络信息的真实性。

## ✨ 功能特性

- ✅ **一键核查**：选中网页文字，点击插件图标即可核查
- ✅ **AI驱动**：使用GLM-5大模型进行深度推理分析
- ✅ **证据链展示**：提供支持性/反对性/中性证据的完整证据链
- ✅ **简洁界面**：现代Google风格设计，清晰直观
- ✅ **实时搜索**：基于智谱AI联网搜索获取最新信息

## 📦 安装步骤

### 1. 准备图标文件

在 `icons/` 目录下放置以下图标：
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

> 💡 **临时方案**：可以先创建任意PNG图片作为占位，或使用在线工具生成简单图标

### 2. 启动后端服务

```bash
cd backend
python main.py
```

后端服务将在 `http://localhost:8000` 启动。

### 3. 加载插件到Chrome

1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 打开右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `browser-extension` 文件夹
6. 插件安装完成！

## 🚀 使用方法

### 基本使用流程

1. **打开任意网页**（如新闻网站、社交媒体等）
2. **选中要核查的文字**（例如一段新闻、一个声明）
3. **点击工具栏的插件图标**（🔍）
4. **在弹窗中点击"开始核查"按钮**
5. **等待10-30秒**，查看核查结果

### 查看结果

核查结果包括：

- **核查结论**：属实/不实/信息不足
- **置信度**：AI对结果的置信程度
- **推理过程**：AI的分析思路
- **证据链**：
  - ✅ 支持性证据（绿色）
  - ❌ 反对性证据（红色）
  - ⚪ 中性证据（灰色）
- **统计信息**：证据总数、权威来源数、平均评分
- **关键发现**：最重要的发现总结
- **注意事项**：不确定性和限制说明

## 🐛 常见问题

### Q: 点击插件图标没有反应？
A: 请确保：
1. 后端服务已启动（`python backend/main.py`）
2. Chrome开发者模式已开启
3. 插件已正确加载

### Q: 提示"无法获取选中的文字"？
A: 请先刷新当前网页，然后重新选中文字。

### Q: 核查结果一直显示"加载中"？
A: 请检查：
1. 后端服务是否正常运行
2. 浏览器控制台是否有错误信息
3. API地址是否正确（`http://localhost:8000`）

### Q: 核查速度很慢？
A: 这是正常的，因为：
1. 需要联网搜索相关信息
2. GLM-5模型需要进行深度推理
3. 通常需要10-30秒
