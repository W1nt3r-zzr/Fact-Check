# 图标说明

请在此目录下放置以下尺寸的图标文件：

- icon16.png (16x16像素) - 工具栏小图标
- icon48.png (48x48像素) - 扩展管理页面图标
- icon128.png (128x128像素) - Chrome Web Store图标

## 临时方案

在开发测试阶段，您可以使用以下任一方法：

### 方法1：使用在线图标生成器
访问以下网站生成简单的图标：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

建议设计：
- 主色调：蓝色 (#1a73e8)
- 图标元素：放大镜 🔍
- 背景：白色或透明

### 方法2：使用纯色占位图
如果暂时没有图标，可以创建简单的纯色PNG图片。

## 设计建议

图标设计应包含：
- **放大镜元素**：象征"搜索"、"核查"
- **对勾元素**：象征"验证"、"真实"
- **简洁风格**：遵循Material Design原则

## 推荐设计

```
┌─────────────────┐
│  🔍✓           │  蓝色放大镜 + 绿色对勾
│  AI Check       │  白色背景
└─────────────────┘
```

可以使用Figma、Sketch或在线工具如Canva进行设计。
