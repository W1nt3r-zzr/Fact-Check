### 功能特点
- 5个高保真场景（微信群、社交媒体、知乎、百度、AI助手）
- **预览页/详情页高保真区分**：所有场景提供预览和详情两种界面
  - 微信群聊：群聊消息列表 vs 文章内容页
  - 社交媒体：瀑布流推荐 vs 笔记详情页
  - 知乎问答：问题列表 vs 问答详情页
  - 搜索引擎：搜索结果 vs 网页内容
  - AI助手：对话历史列表 vs 完整对话
- 3种风险类型（养生谣言、财产诈骗、社会新闻）
- 4种介入方式（弹窗、气泡、右键菜单、日报）
- AI幻觉内容展示
- **"分享后链路"行为追踪**（核心创新）
  - 基于用户访谈洞察设计
  - 为每个场景提供情境化行为选项
  - 家庭微信群特别提供"保全面子"选项（私聊、小群商议、委婉提醒等）
- 6步用户调研流程
- 完整数据记录（场景、风险、介入方式、用户行为、评分）

## 安装步骤

### 选项1: 仅使用用户调研工具
```bash
cd scenario-research
npm install
npm run dev
# 访问 http://localhost:3000
```

### 选项2: 完整开发环境（包括插件和后端）

#### 1. 克隆项目
```bash
git clone [repository-url]
cd 交互-毕业论文
```

#### 2. 安装用户调研工具依赖
```bash
cd scenario-research
npm install
```

#### 3. 安装后端依赖
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

#### 4. 安装插件依赖
```bash
cd extension
npm install
```

### 4. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 文件，填入API密钥
```

### 5. 启动开发服务器
```bash
# 启动后端
cd backend
uvicorn app.main:app --reload --port 8000

# 启动前端 (新终端)
cd extension
npm run dev
```

## 注意事项

1. **API密钥安全**: 绝对不要将API密钥提交到版本控制系统
2. **跨域问题**: 开发时需要配置CORS允许插件访问后端
3. **浏览器权限**: 插件需要在manifest.json中声明必要权限
4. **性能优化**: 注意API调用频率限制，实现适当的缓存策略
5. **错误处理**: 完善的错误处理和用户友好的错误提示
